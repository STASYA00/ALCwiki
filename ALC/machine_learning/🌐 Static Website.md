Ever needed to build a ```static website```? In the era of complex frameworks and tools, understanding the fundamentals of static web development is crucial. These slides explain basic concepts showing how to create and deploy static websites **from scratch**. While modern tools might automate many processes, these basics are critical when working with web technologies - independent of the frameworks.

These slides can be used to create a narrative for:
* 📐 architects & engineers
* 👗🎨 designers
* 🌃 urban planners
* ...people from humanitarian backgrounds even though examples are not _tailored_ for them

**What to expect:**
* 🎨 visual explanation
* 🌐 web development fundamentals

**Wrong place to look for:**
* 🧾 lots of text
* ➕ complex frameworks
* ⭐ fancy buzzwords
* 🏃🏼‍♀️ learning **shortcuts** - quality is a thing here :)

This material can be presented with hands-on exercises for building and deploying static websites.

**Suggested steps:**

* presentation ~20min
* explaining [GitHub Pages](https://pages.github.com/) - optional ~5min
* explaining [git](https://github.com/) - semioptional ~10min
* breakout rooms: 3-4 people, discussing their understanding of web technologies and static vs dynamic websites
* hands-on practice building and deploying a static website 👇🏼
