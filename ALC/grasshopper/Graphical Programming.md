Graphical programming can be a good option to start with coding. It's an intuitive tol that does not require you to know any programming language at all. A perfect entry point!



**Some examples:**

* [Rhino](https://www.rhino3d.com/) -> [Grasshopper](https://grasshopperdocs.com/)
* [Beegraphy](https://beegraphy.com/) - web-based modelling tool based on graphical programming
* [Autodesk Revit](https://www.autodesk.com/se/products/revit/overview)-> [Dynamo](https://dynamobim.org/)
* [Autodesk Maya](https://www.autodesk.com/products/maya)
* [Blender](https://www.blender.org/) - shaders & geometry
* [Adobe Substance Designer](https://www.adobe.com/products/substance3d/apps/designer.html) - procedural materials
* [Houdini](https://www.sidefx.com/products/houdini/)
* [Nuke](https://www.foundry.com/products/nuke-family/nuke) - VFX
