Do you remember working in a group with that guy who would _only_ use Sketchup in his projects? Even if everyone else was sitting with Rhino? There is hardly an architectural project that went without these interplatform issues. Even if you are working alone you might need to export your model from Rhino and perform some analysis in  [[Grasshopper]]. Or render it with that fancy lighting in 3DsMax or Blender.

A few companies have been working on solving this collaboration challenge.

### Tools & References

💜 [That Open Company](https://thatopen.com/) - open-source technology for sending data between software programs. They also have the [best documentation](https://docs.thatopen.com/intro) in the world 💜\
💙 [Speckle](https://www.speckle.systems/) - intuitive tool for sending data between software programs
